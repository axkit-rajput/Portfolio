## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (tested on Node.js v24)
- npm 9+

### Installation & Local Development

```bash
# Clone the repository
git clone https://github.com/axkit-rajput/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build & Preview

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deployment to Vercel

1. Push this repository to your GitHub account (`https://github.com/axkit-rajput/portfolio`).
2. Log into [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import the `portfolio` repository.
4. Keep the default settings:
   - **Framework Preset**: Vite
   - **Root Directory**: `./`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **"Deploy"**. The site will be live on Vercel with automatic CI/CD on every push.
