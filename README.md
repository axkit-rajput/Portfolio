# Ankit Mewada — Portfolio

Personal developer portfolio showcasing my work in artificial intelligence, distributed systems, and full-stack engineering.

🔗 **Live Link:** [axkit-rajput.github.io/Portfolio](https://axkit-rajput.github.io/Portfolio/)

---

## Overview

Designed and built from scratch as a focused, dark-mode developer portfolio.

- **Editorial Dark Aesthetic**: High contrast carbon palette (`#0C0D12` / `#E05D38`), subtle depth, and smooth Framer Motion interactions.
- **Deep Technical Breakdowns**: Interactive architectural diagrams, system flow blueprints, and design rationales for featured systems.
- **Responsive & Mobile-First**: Built with fluid layouts, responsive typography, and tested across mobile, tablet, and desktop viewports.
- **Direct Reach**: Instant communication via WhatsApp, Email, LinkedIn, and GitHub.

---

## Featured Work

- **AnkAI (Multi-Agent AI Orchestration Platform)**: LangGraph StateGraph routing across specialized agents, vector retrieval via Qdrant, and microservice backend with architectural diagrams.
- **Credit Ledger (Explainable Credit Risk Assessment)**: 32.5K record ML pipeline, Platt scaling probability calibration, SHAP TreeExplainer attributions, and FastAPI inference flow.

---

## Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS
- **Motion**: Framer Motion
- **Icons**: Lucide Icons
- **Bundler**: Vite
- **Deployment**: GitHub Pages (Automated via GitHub Actions)

---

## Local Development

```bash
# Clone repository
git clone https://github.com/axkit-rajput/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build production bundle
npm run build

# Preview locally
npm run preview
```
